# Archive — Pre-3-Doc Documentation

This folder contains documentation files that existed before the `3-doc` branch was created.
They have been moved here to keep `docs/STATUS.md` as the single source of truth.

## What was here

Prior to Phase 1, the `docs/` directory contained ~80 files including:
- Implementation status reports (DAY_8, DAY_9, PHASE_1, PHASE_3 completion certificates)
- CBDT compliance audits (various versions)
- ITR field guides and discrepancy audits
- ERP execution plans (`.docx` and `.txt`)
- Client-specific documents (PAN-referenced `.zip` and `.txt` files)
- Architecture specifications
- Stack trace logs and crash reports

All of these have been removed from git tracking on the `3-doc` branch.
If you need to recover any specific file, check the git history on the `restructure/cleanup-v1` branch.
