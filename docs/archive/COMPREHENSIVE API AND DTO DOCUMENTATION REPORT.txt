   🔐 AUTHENTICATION APIs

   Backend: `AuthController` (`/api/auth`)

   Endpoint             │ Method │ Request DTO   │ Response DTO   │ Description

   `/api/auth/register` │ POST   │ `AuthRequest` │ `AuthResponse` │ User registration
   `/api/auth/login`    │ POST   │ `AuthRequest` │ `AuthResponse` │ User login

   DTOs:
   •  AuthRequest: { email: string, password: string }
   •  AuthResponse: { token: string, email: string, expiresIn: number }

   Frontend: No dedicated auth API file found in frontend (uses axios directly)

   📋 COMPLETE DTO REFERENCE

   Core ITR Form DTOs

   **Itr1FormData** (ITR-1 Sahaj)

   typescript
     {
       personalInfo: PersonalInfo
       salaryIncome: SalaryIncome
       housePropertyIncome: HousePropertyIncome
       otherSourcesIncome: OtherSourcesIncome
       deductions: Deductions
       taxPayments: TaxPayments
       exemptIncome: ExemptIncome
       taxComputation: TaxComputation
       validationErrors: string[]
       validationWarnings: string[]
     }

   PersonalInfo: assesseeName, pan, aadhaar, dateOfBirth, age, ageCategory, email, mobile, address fields,
   assessmentYear, financialYear, filingType, residentialStatus, regime, employerCategory, bankDetails

   SalaryIncome: salary17_1, perquisites17_2, profitsInLieu17_3, grossSalary, exemptAllowances (HRA, LTA, etc.),
   standardDeduction, professionalTax, incomeFromSalary, employers[]

   HousePropertyIncome: propertyType, address, annualRent, municipalTaxesPaid, standardDeduction30Pct,
   interestOnLoan, incomeFromHP, loanDetails, coOwners[]

   OtherSourcesIncome: savingsAccountInterest, fixedDepositInterest, dividendIncome, familyPension, casualIncome,
   totalOtherSourcesIncome, bankInterestDetails[], dividendDetails[]

   Deductions: 80C (LIC, PPF, ELSS, EPF, NSC, homeLoanPrincipal, tuitionFees, etc.), NPS (80CCD1, 80CCD1B, 80CCD2),
   80D (healthInsurance), 80DD, 80DDB, 80E, 80EE, 80EEA, 80EEB, 80G, 80GG, 80TTA, 80TTB, 80U

   TaxPayments: tdsOnSalary[], tdsOnOther[], tcsEntries[], advanceTaxEntries[], selfAssessmentTaxEntries[]

   TaxComputation: grossTotalIncome, totalDeductions, totalIncome, taxOnNormalIncome, rebate87A, surcharge, cess,
   totalTaxLiability, relief89, interest234A/B/C, fee234F, taxPayable/refund

   **Itr2FormData** (ITR-2)

   Extends ITR-1 with:
   •  Multiple house properties
   •  Capital gains (STCG 111A, LTCG 112A, etc.)
   •  VDA transactions
   •  Schedule AL (Assets & Liabilities)
   •  Schedule FA (Foreign Assets)
   •  Schedule FSI (Foreign Source Income)
   •  Schedule AMT
   •  Loss schedules (CYLA, BFLA, CFL)

   **Itr3FormData** (ITR-3)

   Extends ITR-2 with:
   •  Business/Professional income
   •  Depreciation schedule
   •  GST reconciliation
   •  Profit & Loss statement
   •  Balance Sheet
   •  Audit details
   •  Section 43B disallowances
   •  MSME payments
   •  F&O trading details

   **Itr4FormData** (ITR-4 Sugam)

   Presumptive taxation:
   •  Section 44AD (Business)
   •  Section 44ADA (Professional)
   •  Section 44AE (Goods Carriage)
   •  Simplified Balance Sheet
